# Ounsia+ Shopify theme

Custom Online Store 2.0 theme for **Ounsia+ (أنسية)**, a women's Myo & D-Chiro
Inositol powder brand. Tagline: "Good mood. Daily."

## Upload it
Zip the *contents* of this folder (assets, config, layout, locales, sections,
snippets, templates) and upload it in Shopify admin → Online Store → Themes →
Add theme → Upload zip file. Or with Shopify CLI from this folder:

    shopify theme push --unpublished --store your-store.myshopify.com

## Homepage sections (all editable in the theme editor)
Announcement bar · Hero slideshow with starburst badge · Scrolling trust badges ·
Category cards · Benefit icons · Image + checklist · Featured flavours ·
"Mix & Go" steps · Newsletter footer.

## Product page
- Flavour pills: add an option called "Flavour" (Berry Peach, Mixed Berry,
  Vanilla Bean, Tropical Mango) to the product.
- Subscribe & save box: install the free **Shopify Subscriptions** app and add a
  monthly plan to the product. The box appears automatically. Without a plan,
  only the one-time price is shown.
- Star rating: appears automatically when a reviews app (e.g. Judge.me) fills
  Shopify's standard `reviews.rating` metafields.
- Round image badges, feature icons and the Ingredients / How to use tabs can
  be edited in the theme editor.

## Arabic
Includes an Arabic translation (`locales/ar.json`) and right-to-left layout.
Turn it on in Settings → Languages → Add Arabic.
